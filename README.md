# KotoBalloon

言葉を、コミックに。 / Turn your meetings into comics.

ミーティング音声をリアルタイムでコミックパネルに変換するツール。
D2言語を構造的中間DSLとして用いた、会議トランスクリプト→コミック生成パイプライン。

A real-time pipeline that converts meeting transcripts into comic panels,
using D2 language as a structural intermediate representation (DSL).

このツールはKotoba Whisperを使用しており、日本語の音声・トランスクリプトのみに対応しています。
This tool uses Kotoba Whisper and supports Japanese audio and transcripts only.
